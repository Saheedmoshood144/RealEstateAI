# RealEstateAI

An end-to-end machine learning platform for California housing
valuation, property search, recommendation, and conversational AI.

## Project Status

🚧 Milestone 1 — Data Foundation

## Planned Capabilities

- California housing value prediction
- Property listing search
- Property recommendation
- Natural-language real estate chatbot
- FastAPI backend
- Gradio interface
- MLflow experiment tracking
- Automated testing
- Production-oriented ML pipelines
